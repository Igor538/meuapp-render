## Descrição
`meuapp-render` é um projeto em **Django** que demonstra o deploy de uma aplicação web e a criação de uma **API REST simples**.  
O projeto foi desenvolvido com foco em **aprendizado de desenvolvimento web, back-end em Python e integração com front-end via API**.

Ele inclui:  
- Rota que retorna dados em **JSON** (`api_teste`)  
- Estrutura básica de um projeto Django  
- Configuração para deploy no **PythonAnywhere**
